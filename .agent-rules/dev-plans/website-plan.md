## 当前阶段

用户指定使用三张设计稿中的第三张：白底蓝字大标题、宽幅真实截图和下方场景介绍。采用此前确认的独立 `site/` 静态 HTML/CSS/JS 与 GitHub Pages 部署方案。

## 改动范围

- `site/`：页面、版本数据、自托管资源、构建与检查、设计对照。
- `.github/workflows/pages.yml`：站点自动部署与 Release 完成联动。
- Android CI：增设路径过滤；README 添加官网入口。
- 项目机制及索引：记录网站维护方式。

## 步骤

1. 按第三版实现首页，复用现有图标和真实模拟器截图。
2. 实现官方版本数据校验与静态构建，覆盖项目子路径。
3. 验证导航、下载入口、场景切换、图片放大和 FAQ。

5. 启用 Pages，推送与部署，核验公开地址。
