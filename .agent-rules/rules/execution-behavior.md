# 汇报风格

## 规则

所有汇报一律**通俗易懂且精简，能用一句话讲清就绝不用两句话，但必须讲清楚说明白**。

## 怎么做

1. **结论放在第一句**，先给答案再给理由；背景只在必要时补一句。
2. **不堆术语**：必须用的专有名词，第一次出现时用大白话补一句它干什么。
3. **不为凑结构而写结构**：不需要标题、表格、编号的就不加；三行能说完不写八行。
4. **删空话**："进一步提升了健壮性""为后续打下基础""综上所述"这类没有信息量的句子一律不写。
5. **长内容分两层**：先一句话结论，再给细节；细节本身也要能被单独跳过。
6. **如实记账**：做完 / 只做了一半 / 没做，分开说，不确定的标"未核实"，不粉饰。

## 不要

- 结尾复述刚刚做了什么（用户能看见改动）。
- 用"我将""接下来我将"占行；直接做，直接说结果。
- 把工具输出、日志原文整段贴上来当汇报。
