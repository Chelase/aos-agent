装车前，
你可能想知道。

这是 Android Auto 投屏应用吗？

不是。AOS-Agent 是安装在 Android Automotive OS 车机上的原生应用，面向 Android 12 / API 31 及以上设备，不是手机端投屏插件。

可以适配所有车型、控制车辆吗？

可读取的属性取决于厂商实现和系统授权。当前内置车辆工具以只读查询为主，不承诺通用车型兼容或车辆控制能力；工程师页面可查看能力与缺失原因。

语音和 AI 都能离线运行吗？

Vosk 唤醒在本地运行，中文模型约 42 MB，需单独下载。完整语音识别与播报取决于系统服务。AI 对话使用你配置的模型服务，是否离线取决于该服务的部署方式。

车机无法检查更新，怎么办？

部分实车曾无法连接发布站点，这条问题仍待实车定位与复测。请先分别确认外网、DNS 与 GitHub 发布地址是否可达；也可以在其他设备下载正式 APK，再通过车机允许的方式安装。

升级需要卸载旧版本吗？

正式发布包沿用发布签名，可按系统允许的方式覆盖升级。本地 Debug 包的签名不同，不能直接覆盖正式包。下载校验通过后，应用内更新仍需系统安装器和用户确认。
